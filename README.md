# 🏁 سباق القراءة — Reading Race

لعبة تعليمية لتدريب الطلاب على القراءة الجهرية: يقرأ الطالب النص بصوته فتتقدّم سيارته في السباق،
مع وضع للتصحيح، ونتيجة وقائمة أخطاء ونصيحة للتدرّب، وبثلاث لغات (العربية · English · Français).

**تصميم وإعداد:** الأستاذة منجية عادل — [@ostatha.mongia](https://www.instagram.com/ostatha.mongia/)

## الاستخدام

افتحوا رابط اللعبة في المتصفح (يُفضَّل Google Chrome)، واسمحوا باستخدام الميكروفون.
